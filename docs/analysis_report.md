# 1. How to read this report

This report lists every analysis carried out in the study and every estimate it produced, in the order the
analyses were run. It is generated from the output tables, so its numbers always match the current run of
`./run_all.sh`.

**Units and conventions.**

- All changes are 100 × Δln, so a coefficient is the change in percentage points (pp) per 1% change in the fuel index.
- *Per-horizon* responses (β_h) are effects on the one-month change at horizon *h*. *Cumulative* responses are effects on
  the price level after *h* months.
- Gap = ln(CPI all income / CPI bottom 30%). A negative response means the bottom 30% face larger price increases
  (regressive); a positive response means the average household does (progressive).
- Standard errors in parentheses. \*, \*\*, \*\*\*: significant at 10%, 5%, 1% (two-sided, normal critical values).
  Bands in figures are 90%.
- National models: Newey–West standard errors with h + 1 lags. Regional panel: region fixed effects, Driscoll–Kraay
  standard errors. EU validation: country fixed effects, clustered (or robust) standard errors.
- "nobs_h0" is the number of observations in the h = 0 regression; "units" is 1 for national models and the number of
  regions or countries for panels.

**Status of each analysis.** *Pre-registered*: specified in the decision log before any estimate was produced
(replication gate; RQ1–RQ4 and robustness). *Supplementary*: specified after the first results (RQ3b, sub-period
splits, 2026 episode E1–E4). *Descriptive*: no model (Objective 1 statistics; 2026 decomposition E5).

# 2. Validation

## 2.1 Simulation test (A0)
Data are simulated from y_t = 0.4·y_{t−1} + 0.04·x_t + 0.02·x_{t−1} + 0.01·x_{t−2} + e_t (x ~ N(0, 3²),
e ~ N(0, 0.2²)), whose impulse response is known exactly (0.040, 0.036, 0.0244, …). The tests in `tests/test_lp.py`
require the estimator to recover it within 0.006 at h = 0..6 for (i) a single long series with Newey–West errors,
(ii) a 20-unit panel with clustered errors and (iii) the same with Driscoll–Kraay errors; to recover the cumulative
response within 0.01; and to estimate a known group difference of 0.03 within 0.005. All five tests pass in every
run of `./run_all.sh`.
