# Archive

`v1_full/` is the complete first version of the study (October 2026), kept unchanged as the
full record: the 51-page working paper and its journal manuscript, the FA2 proposal, the SA3
deck, the master document, the full Python pipeline (including the EU replication gate and
every robustness check), and all raw data.

It still runs on its own. From inside `archive/v1_full/`:

```bash
PY=../../.venv/bin/python ./run_all.sh
```

The current version of the study is at the top level of the repository.
